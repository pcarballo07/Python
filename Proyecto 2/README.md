# Proyecto 2 - Análisis de Acciones

Análisis de datos financieros usando la librería `yfinance` para extraer 
información de cotizaciones, calcular estadísticas básicas y graficar resultados.

## ¿Qué hace este proyecto?

- Extrae información de yahoo finace de las acciones de las empresas
- Calcula estadísticas: máximo, mínimo y promedio de cierre
- Genera gráficas de los datos obtenidos
- Crea el PDF
- Lo envia por correo electronico

## Requisitos

- Librerías necesarias: yfinance, matplotlib, fpdf
- Instalalas con pip install yfinance 
- pip install matplotlib 
- pip install fpdf

## Cómo ejecutarlo

1. Clona este repositorio
2. Instala las dependencias (ver arriba)
3. Abre `Proyecto2.ipynb` en VS Code o Jupyter
4. Ejecuta las celdas en orden
